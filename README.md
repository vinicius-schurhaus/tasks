# Tasks

Uma lista de tarefas simples desenvolvida com React.

## Tecnologias

- React
- Vite
- Tailwind CSS
- shadcn/ui
- Lucide React

## Funcionalidades

- Adicionar tarefas
- Editar tarefas
- Concluir tarefas
- Excluir tarefas
- Persistência com localStorage
- Interface responsiva

## Executar

```bash
npm install
npm run dev
```
